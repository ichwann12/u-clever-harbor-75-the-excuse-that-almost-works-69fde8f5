One line a gamer texts the boss to get out of work during GTA 6 launch week:

> Boss, my car broke down outside the game store, and the tow truck only comes on launch day. Terrible timing.

## How it works

`main.ts` (Node 22+, stdlib only, no network, no wall clock) reads the excuse
from `entry.txt` at the repo root and writes it to `entry.txt` inside the
output directory given by `MAKEFUN_OUTPUT_DIR` (or `MAKEFUN_BOT_DIR`).

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
